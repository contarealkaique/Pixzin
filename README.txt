PIXZIN — LIMA CASINO DEMO

COMO PUBLICAR
1. Extraia o ZIP.
2. Envie o conteúdo desta pasta para um deploy manual no Netlify.
3. Confirme que index.html está na raiz da pasta publicada (não dentro de outra subpasta).
4. Abra o endereço publicado no navegador.

MELHORIAS NESTA VERSÃO
- Tabela de créditos virtuais visível na página inicial (5, 10, 25, 50 e 100).
- Botões da tabela atualizam a mesa selecionada.
- Mensagem diária dinâmica (ex.: Sextou com Pixzin).
- Fluxo de autorização via WhatsApp para +55 75 99807-0667.
- Validação dos 100 códigos predefinidos de autorização PZX-001 a PZX-100.
- Campo de código da sala aceita o ID completo da sala PeerJS.
- Link de WhatsApp também no botão flutuante e envio de relatório.
- Fallback de CDN para carregar PeerJS.
- Paleta verde-lima e efeitos sonoros suaves mantidos.

IMPORTANTE
Os valores são créditos fictícios, sem dinheiro, pagamento, saque ou prêmio real. O projeto é estático; códigos no JavaScript não são segurança real. A conexão ao vivo depende do PeerJS/WebRTC, internet e do serviço público de sinalização. JavaScript foi validado sintaticamente; é necessário testar entre dois aparelhos reais depois da publicação.
